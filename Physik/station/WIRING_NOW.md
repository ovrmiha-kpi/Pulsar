# Розводка (обидва ряди OK)

Орієнтир: USB DevKit **знизу**.  
Актуальна **повна** схема всіх модулів: [`WIRING_ALL.md`](WIRING_ALL.md)

```
Правий: 3V3 GND D15 D2 D4 D16 D17 D5 D18 D19 D21 RX0 TX0 D22 D23
Лівий:  VIN GND D13 … D34 D35 VN VP EN  (SD CS=D13, ADC тощо)
```

---

## Що підключено зараз

### TFT 1.8″ ST7735 (увесь на правому ряді)

| TFT | ESP32 правий |
|-----|----------------|
| VCC | **3V3** |
| GND | **GND** |
| CS | **D5** |
| RESET | **D4** |
| A0 (DC) | **D15** |
| SDA (MOSI) | **D23** |
| SCK | **D18** |
| LED | **3V3** |

### MQ-135 (повітря)

На правому ряді **немає нормального ADC1**, тому A0 садимо на **D2** (теж правий ряд, ADC2).  
Поки **Wi‑Fi не вмикаємо** — ADC2 ок.

| MQ-135 | ESP32 |
|--------|-------|
| VCC | **VIN / 5V** (верх лівого ряду — **єдиний** дріт не з правого) |
| GND | **GND** правий |
| A0 | **D2** (правий) |
| D0 | не підключати |

Якщо модуль уже на **D34** — переткни A0 на **D2**.

### BMP280 (температура + тиск) — I²C, правий ряд

| BMP280 | ESP32 |
|--------|-------|
| VCC / VIN | **3V3** |
| GND | **GND** |
| SDA | **D21** |
| SCL | **D22** |

Не плутай SDA BMP з SDA TFT (TFT = D23).  
Адреса зазвичай **0x76** або **0x77** (залежить від SDO на модулі).

Бібліотека: **Adafruit BMP280** (+ Unified Sensor).

### MAX30102 — SKIP

Поки не підключаємо. Пізніше теж D21/D22 (спільна I²C з BMP).

## Карта правого ряду (хто зайнятий)

| Пін | Зараз |
|-----|--------|
| 3V3 | TFT VCC + LED (+ пізніше I²C) |
| GND | спільний |
| D15 | TFT A0/DC |
| **D2** | **MQ-135 A0** ✅ працює |
| D4 | TFT RESET |
| D16 | вільно (пізніше HX711 DT) |
| D17 | вільно (пізніше HX711 SCK) |
| D5 | TFT CS |
| D18 | TFT SCK |
| D19 | вільно (SPI MISO / SD) |
| D21 | I²C SDA → **BMP280** |
| RX0/TX0 | не чіпати (USB Serial) |
| D22 | I²C SCL → **BMP280** |
| D23 | TFT SDA/MOSI |

## Повна стара карта (на потім, лівий ряд теж)

Це було в плані станції — **поки не збираємо**:

| GPIO | Було | Сторона |
|------|------|---------|
| 13 | SD_CS | ліва |
| 34 | MQ_A0 (стара) | ліва → **замінено на D2** |
| 35 | ECG | ліва |
| 25–27, 14, 32, 33 | кнопки | ліва |
| 12 | LED | ліва |
| 2 | був BUZZ | правий → **зараз MQ A0** |

Зумер/кнопки/SD/ECG — після того, як відкриємо лівий ряд.
