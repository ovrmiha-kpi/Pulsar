# Повна розводка — усі куплені модулі

Орієнтир ESP32 DevKit: **USB знизу**.  
Можна використовувати **обидва ряди** пінів (лівий і правий).  
Прошивку **не лий**, поки не скажеш — спочатку збері дроти за цією таблицею.

**Спільні шини**
- **SPI:** TFT + microSD → SCK=D18, MOSI=D23, MISO=D19; різні CS
- **I²C:** BMP280 + MAX30102 + MPU-6500 → SDA=D21, SCL=D22 (паралельно)

Усі **GND** — у спільну землю ESP32.  
**3V3** — тільки 3.3 В. **VIN/5V** — тільки модулі, яким треба 5 В.

---

## 1) TFT 1.8″ ST7735 (SPI 128×160)

| TFT | ESP32 |
|-----|-------|
| VCC | **3V3** |
| GND | **GND** |
| CS | **D5** |
| RESET | **D4** |
| A0 | **D15** |
| SDA | **D23** |
| SCK | **D18** |
| LED | **3V3** |

---

## 2) microSD (SPI)

| SD | ESP32 |
|----|-------|
| VCC / 3V3 | **3V3** |
| GND | **GND** |
| CS | **D13** (лівий ряд) |
| MOSI / DI | **D23** |
| MISO / DO | **D19** |
| SCK / CLK | **D18** |

Картку встав після проводки.

---

## 3) BMP280 (I²C) — T + тиск

| BMP280 | ESP32 |
|--------|-------|
| VCC | **3V3** |
| GND | **GND** |
| SDA | **D21** |
| SCL | **D22** |

Адреса 0x76 або 0x77.

---

## 4) MAX30102 (I²C) — пульс / SpO2

| MAX30102 | ESP32 |
|----------|-------|
| VIN / VCC | **3V3** |
| GND | **GND** |
| SDA | **D21** |
| SCL | **D22** |
| INT | не підключати |

Палець на сенсор (LED). Штирі мають бути припаяні.

---

## 5) MPU-6500 (I²C) — IMU

| MPU-6500 | ESP32 |
|----------|-------|
| VCC | **3V3** |
| GND | **GND** |
| SDA | **D21** |
| SCL | **D22** |
| ADO / AD0 | GND (адреса 0x68) або 3V3 (0x69) — як на модулі |
| INT | не обов’язково |

---

## 6) MQ-135 — якість повітря

| MQ-135 | ESP32 |
|--------|-------|
| VCC | **VIN / 5V** (або 3V3, якщо так уже працює) |
| GND | **GND** |
| A0 | **D2** |
| D0 | не підключати |

---

## 7) HX711 + тензодатчик (вага / хват)

На DevKit піни часто підписані **RX2 / TX2**, а не D16/D17 — це ті самі GPIO:

| HX711 | ESP32 (підпис на платі) | GPIO |
|-------|-------------------------|------|
| VCC | **VIN** | 5V |
| GND | **GND** | GND |
| DT / DOUT | **RX2** | **16** |
| SCK | **TX2** | **17** |
| E+ E− A+ A− | тензодатчик | — |

---

## 8) Окремий датчик пульсу (аналоговий) — опційно

Якщо модуль типу KY-039 / «Heart Rate»:

| Pulse | ESP32 |
|-------|-------|
| VCC | **3V3** |
| GND | **GND** |
| S / Signal | **D34** (лівий ряд, ADC) |

Якщо використовуєш лише MAX30102 — цей модуль можна не чіпати.

---

## Карта пінів ESP32 (хто зайнятий)

| GPIO | Призначення |
|------|-------------|
| 3V3 | TFT, SD, BMP, MAX, MPU, LED TFT |
| GND | усі |
| VIN/5V | MQ, HX711 |
| **D2** | MQ A0 |
| **D4** | TFT RESET |
| **D5** | TFT CS |
| **D13** | SD CS |
| **D15** | TFT A0/DC |
| **RX2 (D16)** | HX711 DT |
| **TX2 (D17)** | HX711 SCK |
| **D18** | SPI SCK (TFT+SD) |
| **D19** | SPI MISO (SD) |
| **D21** | I²C SDA (BMP+MAX+MPU) |
| **D22** | I²C SCL |
| **D23** | SPI MOSI (TFT+SD) |
| **D34** | аналог. пульс (опц.) |
| RX0/TX0 | USB — не чіпати |

---

## Порядок збірки (щоб не плутати)

1. TFT  
2. I²C-шина: BMP280 → MAX30102 → MPU-6500 (усі на 21/22 + 3V3/GND)  
3. MQ-135  
4. microSD  
5. HX711  
6. Аналог. пульс — за бажанням
