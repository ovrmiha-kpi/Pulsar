# Повна розводка — усі куплені модулі

Орієнтир ESP32 DevKit: **USB знизу**.  
Можна використовувати **обидва ряди** пінів (лівий і правий).  
Прошивку **не лий**, поки не скажеш — спочатку збері дроти за цією таблицею.

**Спільні шини**
- **SPI TFT (сторона 1):** SCK=D18, MOSI=D23, CS=D5, DC=D15, RST=D4
- **SPI microSD (сторона 2, окрема шина):** SCK=D14, MOSI=D13, MISO=D32, CS=D33
- **I²C:** BMP280 + MAX30102 + MPU-6500 → SDA=D21, SCL=D22 (паралельно)

Усі **GND** — у спільну землю ESP32.  
**3V3** — тільки 3.3 В. **VIN/5V** — тільки модулі, яким треба 5 В.

## 1) TFT 1.8″ ST7735 (SPI 128×160)

| TFT | ESP32 |
|-----|-------|
| VCC | **3V3** |
| GND | **GND** |
| CS | **D5** |
| RESET | **D4** |
| A0 | **D15** |
| SDA | **D23** |
| SCK | **D18** |
| LED | **3V3** |

---

## 2) microSD (SPI) — **уся на стороні 2** (ряд VIN, USB знизу)

Окрема шина, **не** ділити з TFT. Орієнтир: USB знизу → **права** сторона плати (VIN / D13 / D14…).

| SD | ESP32 (сторона 2) |
|----|-------------------|
| VCC / 3V3 | **3V3** (якщо на цій стороні немає — протягни з лівого 3V3) |
| GND | **GND** (поруч із VIN на цій же стороні) |
| CS | **D33** |
| MOSI / DI | **D13** |
| MISO / DO | **D32** |
| SCK / CLK | **D14** |

Не чіпай D18/D19/D23 — вони лишаються тільки для TFT.  
Картку встав після проводки.

---

## 3) BMP280 (I²C) — T + тиск

| BMP280 | ESP32 |
|--------|-------|
| VCC | **3V3** |
| GND | **GND** |
| SDA | **D21** |
| SCL | **D22** |

Адреса 0x76 або 0x77.

---

## 4) MAX30102 (I²C) — пульс / SpO2

| MAX30102 | ESP32 |
|----------|-------|
| VIN / VCC | **3V3** |
| GND | **GND** |
| SDA | **D21** |
| SCL | **D22** |
| INT | **не підключати** (пульс рахуємо в ПЗ по IR) |

Палець **щільно** на скло (має світитись червоний). Штирі припаяні.  
Потрібно лише: **3V3, GND, SDA→D21, SCL→D22**. Якщо SpO₂ є, а HR немає — це ПЗ/контакт пальця, не «забутий INT».

---

## 5) MPU-6500 (I²C) — IMU

| MPU-6500 | ESP32 |
|----------|-------|
| VCC | **3V3** |
| GND | **GND** |
| SDA | **D21** |
| SCL | **D22** |
| ADO / AD0 | GND (адреса 0x68) або 3V3 (0x69) — як на модулі |

| MQ-135 | ESP32 |
|--------|-------|

## 7) HX711 + тензодатчик (вага / хват)

На DevKit піни часто підписані **RX2 / TX2**, а не D16/D17 — це ті самі GPIO:

| HX711 | ESP32 (підпис на платі) | GPIO |
|-------|-------------------------|------|
| VCC | **VIN** | 5V |
| GND | **GND** | GND |
| DT / DOUT | **RX2** | **16** |
| SCK | **TX2** | **17** |
| E+ E− A+ A− | тензодатчик | — |

---

## 8) Окремий датчик пульсу (аналоговий) — опційно

Якщо модуль типу KY-039 / «Heart Rate»:

| Pulse | ESP32 |
|-------|-------|
| VCC | **3V3** |
| GND | **GND** |
| S / Signal | **D34** (лівий ряд, ADC) |

Якщо використовуєш лише MAX30102 — цей модуль можна не чіпати.

---

## 9) Кнопки ×3 (тактові **4 піни**, до GND)

Лівий ряд DevKit. Режим: **INPUT_PULLUP** (натиснуто = **LOW**).  
Резистори не потрібні.

У 4-пінової кнопки піни йдуть **парами по боках**:
- ліва пара (1–2) **завжди з’єднана** між собою;
- права пара (3–4) **завжди з’єднана** між собою;
- при натисканні з’єднуються **ліва ↔ права**.

Тобто це та сама 2-контактна кнопка: береш **один пін зліва** і **один справа**.

```
      вид зверху (ніжки вниз):

        1 ●────────● 4
          │  (кнопка) │     при натисканні: ліва сторона ↔ права
        2 ●────────● 3

      підключення (будь-яка діагональ або сусідні з різних сторін):

        ESP32 GPIO ──● 1          4 ●── GND
                     │              │
                   (не чіпати 2 і 3, або продублювати той самий дріт)
```

Практично: **дріт на будь-який лівий ніжку → GPIO**, **дріт на будь-який правий ніжку → GND**. Два інші ніжки можна не підключати.

| Кнопка | Роль (логіка UI) | ESP32 (один пін зліва) | GND (один пін справа) |
|--------|------------------|------------------------|------------------------|
| **BTN1** | Select / OK | **D25** | **GND** |
| **BTN2** | Next / ↓ | **D26** | **GND** |
| **BTN3** | Back / ↑ | **D27** | **GND** |

```
ESP32 D25 ── (ліва сторона BTN1) ── (права сторона) ── GND
ESP32 D26 ── (ліва сторона BTN2) ── (права сторона) ── GND
ESP32 D27 ── (ліва сторона BTN3) ── (права сторона) ── GND
```

**Важливо:** не бери два піни **з одного боку** (1+2 або 3+4) — вони завжди замкнені, GPIO буде вічно LOW і кнопки «не працюють».

Якщо Serial показує `D25=0 D26=0 D27=0` постійно — саме ця помилка. Візьми **діагональ** (1 і 3, або 2 і 4) або один пін зліва + один справа.

## Карта пінів ESP32 (хто зайнятий)

| GPIO | Призначення |
|------|-------------|
| 3V3 | TFT, SD, BMP, MAX, MPU, LED TFT |
| GND | усі (+ кнопки) |
| VIN/5V | MQ, HX711 |
| **D2** | MQ A0 |
| **D4** | TFT RESET |
| **D5** | TFT CS |
| **D13** | SD MOSI (сторона 2) |
| **D14** | SD SCK (сторона 2) |
| **D15** | TFT A0/DC |
| **RX2 (D16)** | HX711 DT |
| **TX2 (D17)** | HX711 SCK |
| **D18** | TFT SCK |
| **D19** | вільний (був SD MISO) |
| **D21** | I²C SDA (BMP+MAX+MPU) |
| **D22** | I²C SCL |
| **D23** | TFT MOSI |
| **D25** | BTN1 Select |
| **D26** | BTN2 Next |
| **D27** | BTN3 Back |
| **D32** | SD MISO (сторона 2) |
| **D33** | SD CS (сторона 2) |
| **D34** | аналог. пульс (опц.) |
| RX0/TX0 | USB — не чіпати |

## Прошивка годинника + SD

`Physik/watch/pulsar_watch/pulsar_watch.ino`  
- **немає LINK** (ні BT-клієнта, ні `LINK` від `npm run bt`) → JSON пишеться в `/pulsar.jsonl` на SD  
- **з’явився LINK** → дамп файлу в USB/BT і **очищення** SD  
Піни SD: CS33 SCK14 MOSI13 MISO32 (сторона 2).
