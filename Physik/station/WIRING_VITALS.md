# SpO2 + якість повітря → TFT

Екран лишається як у `WIRING_TFT.md`. Додаємо **MAX30102** і (коли буде) **MQ-135**.

## MAX30102 (кисень у крові / пульс) — I²C, правий ряд

| MAX30102 | → | ESP32 |
|----------|---|-------|
| VIN / VCC | → | **3V3** |
| GND | → | **GND** |
| SDA | → | **D21** (правий ряд) |
| SCL | → | **D22** (правий ряд) |

INT не обов’язковий. Палець на сенсор (LED вгору).

## MQ-135 (якість повітря) — модуль з металевою сіткою-ковпаком

Типові піни на платі: **VCC · GND · DO · AO** (цифровий DO поки не потрібен).

| MQ-135 | → | ESP32 |
|--------|---|-------|
| VCC | → | **5V** (або VIN) |
| GND | → | **GND** |
| A0 / AO | → | **D34** (лівий ряд, ADC) |
| D0 / DO | → | не підключати |

Якщо A0 дає до 5 В — подільник **10 кΩ + 20 кΩ** на D34 (≤3.3 В). Багато модулів уже з рівнем під ESP — тоді AO напряму на D34.  
У скетчі за замовчуванням `#define HAS_MQ135 0` (повітря ще не в схемі). Після підключення постав `1`. Нагрівач MQ прогрівається **кілька хвилин**.

Спочатку прожени [`sensor_check`](sensor_check/sensor_check.ino) · [`WIRING_SENSORS.md`](WIRING_SENSORS.md).
