# Pulsar Scan — карта станції (RF / скелет)

Окремий прототип **без зв’язку** з `prototype/server`. Тут лише карта модулів і демо «де хто стоїть» через радіосигнал.

Запуск:

```bash
cd prototype/scan
npm start
# http://127.0.0.1:4300
```

---

## Як це взагалі реалізується (коротко)

Ідея не «сканувати інтернет», а **локально** дивитись, як тіло людини змінює радіохвилі в кімнаті.

### 1. Wi‑Fi CSI (Channel State Information)

- Звичайний Wi‑Fi (часто 5 GHz) шле OFDM-піднесучі.
- Людина відбиває / розсіює сигнал → змінюються **амплітуда і фаза** на кожній піднесучій у часі.
- З кількох антен / точок доступу отримують матрицю CSI.
- Нейромережа (або класичний пайплайн на кшталт Widar) вчиться мапити CSI → координати / суглоби.
- Навчання зазвичай **cross-modal**: камера дає ground-truth скелет (OpenPose тощо), радіо вчиться повторювати; у проді камера не потрібна.

Приклади робіт: CSI-Former, MetaFi, Person-in-WiFi 3D (CVPR 2024).

### 2. FMCW / RF-Pose (радароподібний сигнал)

- Спец. радіо (низька потужність) + антенні решітки.
- Відбиття → теплові карти відстані / кута.
- Мережа збирає кілька кадрів у часі (одне «фото» RF занадто грубе) і видає keypoints скелета, навіть **крізь стіну**.
- Класика: RF-Pose (MIT).

### 3. Що реально треба для станції

| Шар | Що |
|-----|----|
| Залізо | 2–3 Wi‑Fi NIC з CSI (Intel 5300 / Atheros) або mmWave / FMCW радар |
| Калібрування | карта кімнати, позиції антен, синхрон з камерою під час тренування |
| Модель | CNN/Transformer: CSI або heatmap → (x,y) людини + 13–17 суглобів |
| Вихід | track id, позиція на плані, скелет, confidence |

У цьому прототипі **немає реального CSI** — лише симуляція руху людей і скелетів на плані Hab / Lab / Airlock, плюс «антени» як майбутні точки вимірювання.

Коли будете готові підключати до Pulsar — окремим кроком: Scan публікує позиції → server/WS → site. Зараз навмисно ізольовано.
