# PULSAR — презентація

**Файл для захисту:** [`PULSAR_Pitch.pptx`](PULSAR_Pitch.pptx)

Пересобрати після змін:

```powershell
cd prototype\pitch
py -3 build_pptx.py
```

- Акцент: проблема NASA → годинник + станція → що дає екіпажу
- Середовище: **температура навколишнього середовища + атмосферний тиск** (не шкіри)
- Скрини й фото модулів у `media/`
- Слоти під ваші фото годинника — вставте вручну в PowerPoint на слайді «On the wrist»

HTML (`index.html`) — лише чернетка; для виступу використовуйте **PPTX**.
