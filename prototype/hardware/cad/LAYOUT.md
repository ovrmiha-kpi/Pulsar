# Pulsar — компактний корпус (годинник)

Файли: `PulsarWatch.FCStd`, `PulsarWatch.stl`  
Габарит корпусу: **60 × 46 × 24 мм** (+ ремінці).

## Орієнтація

| Сторона | Що | Навіщо |
|---------|-----|--------|
| **Низ (−Z)** → зап’ястя | **MAX30102** у вікні | LED/фотодіод дивиться на шкіру |
| **Верх (+Z)** | **TFT 1.8″** | екран |
| **+Y** (дальній край) | **MQ-135** + вентиляція | гарячий сенсор, окремо від клімату |
| **−Y** (протилежний) | **BMP280** | температура/тиск далеко від MQ |
| між ними | **ThermalBarrier** | зменшує нагрів BMP від MQ |
| всередині | ESP32, MPU-6500, HX711, батарея, HW-373, microSD | стек під екраном |
| **+X** | BTN1–3 | бокові кнопки |
| ±X вушка | ремінець | |

## Правило тепла

MQ-135 гріється → **не ставити поруч із BMP280**. У моделі вони на **протилежних** коротких сторонах корпусу.
